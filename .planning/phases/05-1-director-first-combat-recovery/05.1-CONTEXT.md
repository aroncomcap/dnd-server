# Phase 5.1 Context: Director-First Combat Recovery And Target Authority

## User Decisions

- Scope: full repair pass.
- Strategic boundary: server decides tactical combat; AI narrates/directs only when that adds value.
- Parseable single-action combat should use terse tactical log output by default instead of paying for a narration LLM call.
- Combat remains round-by-round by default.
- If a fight is nearly decided, cinematic compression may be offered but must not be forced.
- If only one active player is present, cinematic finish may proceed immediately.
- Recovery control label: `Move to Next Beat`.
- Recovery should preserve durable campaign state while clearing ephemeral scene/combat state.

## Production Findings

- Social/routing scenes can still derail into combat when the parser or narration over-weights nearby hostile text.
- Targetless or invalid actions can consume turn flow and resources.
- Generic combat options over-emphasize attack/defend and can make stuck combat worse.
- The UI needs persistent player-selected target context so spell/skill/action buttons do not rely on fragile text guesses.

## Bug Slugs Feeding This Phase

- `quest_beats_over_random_encounters_preserve_player_intent_and_do_not_derail_to_combat`
- `advance_story_beats_not_blocked_by_nonhostile_scene_text_or_partial_input`
- `target_required_actions_must_validate_or_prompt_before_resolution`

## Implementation Constraints

- Preserve existing combat-engine math where possible.
- Do not let invalid targets advance turns, trigger enemy turns, or spend spell slots.
- Prefer deterministic server validation over LLM judgment for target-required actions.
- Prefer deterministic tactical output over AI flavor for low-value actions like a single sword swing.
- Keep UI additions compact because the game screen is already dense on mobile.

## Runtime Strategy

- Intent router: cheap deterministic classification first, with dialogue/progress defaulting away from combat unless violence is explicit.
- Rules kernel: server owns turn order, targets, resources, dice math, HP, enemy turns, and combat start/end.
- Director/narrator: AI handles story beat advancement, scene framing, meaningful aftermath, and ambiguous creative actions that deterministic rules cannot parse.
