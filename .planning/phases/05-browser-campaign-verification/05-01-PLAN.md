# Plan 05-01: Preserve Player Intent And Actionable GM Feedback

## Goal

Fix the production-stabilization issues where non-hostile player intent, partial commands, or nearby scene text can derail the main quest beat into combat, and make GM feedback controls produce actionable bug reports with enough trace context for future Codex repair passes.

## Context

Live play showed over-aggressive scene interpretation: merchant/watch/social routing scenes were treated like combat encounters, generic options pushed players toward attacks, and OOC/review feedback produced useful human insight without a durable engineering signal. The current phase remains Browser Campaign Verification, but this local fix is needed before the next production campaign run is meaningful.

## Work Breakdown

1. Update action parsing so dialogue, parley, negotiation, questions, peace offers, travel, acknowledgement, and scene-transition input resolve as non-hostile dialogue or progress.
2. Guard combat and narration extraction so merchant/social/routing scenes only enter combat when the player clearly chooses violence, a hostile spell, or an unavoidable hard failure.
3. Preserve main quest beats in prompt construction by prioritizing stated objectives and treating ambiguous input as conversation or progress.
4. Collapse narration feedback to actionable controls only: Rules, Context, Redo Options, Retcon, and Review.
5. Add Retcon OOC mode and Redo Options regeneration with decision-trace bug logging.
6. Extend bug report storage with slug, source, and decision trace metadata.
7. Add focused parser and UI regression coverage.
